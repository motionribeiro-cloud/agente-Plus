# Vídeo explicativo: ensinar uma ideia

Organize a sequência pela pergunta que o público precisa responder. Uma estrutura possível é problema, mecanismo, exemplo, resultado e próximo passo. Adapte-a ao assunto.

Cada cena deve acrescentar informação ou esclarecer uma relação. Use diagramas, comparações, passos e exemplos concretos para tornar o raciocínio visível. Evite ilustrar cada palavra quando uma representação consistente explica melhor.

## Construção e revisão

- Escreva a ideia principal de cada cena em uma frase.
- Escolha uma representação: processo, mapa, comparação, causa e efeito ou demonstração.
- Defina quais elementos permanecem entre cenas para o público não reaprender a linguagem visual a cada corte.
- Mostre dependências na ordem em que são necessárias à compreensão.
- Confira o timing com a locução real quando ela existir. Sem áudio aprovado, identifique o timing como provisório.

Peça a alguém que explique o argumento depois de assistir ao rascunho. Dificuldade para acompanhar uma relação exige rever conteúdo ou tempo de leitura antes de acrescentar efeitos. Verifique termos, unidades, legendas e fontes das afirmações.
